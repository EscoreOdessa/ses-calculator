# Шаг 1. Получаем ключ Google Maps API

Делается один раз, ~10 минут. Выполняй под тем же Google-аккаунтом, где лежит таблица.

## 1. Создать проект
1. Открой https://console.cloud.google.com
2. Вверху, рядом с логотипом Google Cloud, нажми на список проектов → **New Project / Создать проект**.
3. Имя, например `ESCORE-Maps` → **Create**. Подожди ~10 сек, затем выбери этот проект в том же списке вверху.

## 2. Включить биллинг (карта)
1. Меню слева (☰) → **Billing / Оплата**.
2. **Link a billing account / Привязать аккаунт оплаты** → создай аккаунт оплаты, привяжи банковскую карту.
   > Карта обязательна для активации, но при ваших объёмах списаний не будет — бесплатный лимит 10 000 вызовов/мес на каждый сервис.

## 3. Включить нужные API
1. Меню (☰) → **APIs & Services → Library / Библиотека**.
2. Найди и открой каждый, нажми **Enable / Включить**:
   - **Maps JavaScript API** (интерактивная карта)
   - **Maps Static API** (картинка для КП)
   - **Geocoding API** (адрес → координаты)

## 4. Создать ключ
1. **APIs & Services → Credentials / Учётные данные**.
2. **+ Create credentials → API key**.
3. Скопируй появившийся ключ (длинная строка `AIza...`). **Сохрани его** — он понадобится для инструмента.

## 5. (Желательно) Ограничить ключ — чтобы им не воспользовались чужие
В окне ключа (Credentials → клик по ключу):
1. **API restrictions → Restrict key** → отметь три API из шага 3 → **Save**.
2. Ограничение по сайту (referrer) добавим позже, когда будет готов адрес инструмента — я подскажу, что вписать.
