# Налаштування Google Cloud для веб-калькулятора

Потрібно один раз, ~10 хвилин, для розділу «Розкладка панелей» (карта + пошук адреси).
Розділ «Калькулятор» і «Дані» працюють без цього кроку.

## 1. Створити проєкт
1. Відкрий https://console.cloud.google.com
2. Вгорі, біля логотипу Google Cloud, натисни на список проєктів → **New Project / Створити проєкт**.
3. Назва, наприклад `ESCORE-Calculator` → **Create**. Зачекай ~10 сек, потім вибери цей проєкт у тому самому списку вгорі.

## 2. Увімкнути білінг (карта оплати)
1. Меню зліва (☰) → **Billing / Оплата**.
2. **Link a billing account** → створи акаунт оплати, прив'яжи банківську картку.
   > Картка обов'язкова для активації, але списань не буде — безкоштовний ліміт 10 000 викликів/міс на кожен сервіс, для одного відділу продажів цього більш ніж достатньо.

## 3. Увімкнути потрібні API
1. Меню (☰) → **APIs & Services → Library / Бібліотека**.
2. Знайди і відкрий кожен, натисни **Enable / Увімкнути**:
   - **Maps JavaScript API** (сама карта)
   - **Geocoding API** (адреса → координати)

   (Maps Static API не потрібен — картинка розкладки малюється на сторінці, без завантаження супутникового знімка.)

## 4. Створити ключ
1. **APIs & Services → Credentials / Облікові дані**.
2. **+ Create credentials → API key**.
3. Скопіюй ключ (рядок `AIza...`).

## 5. Обмежити ключ (важливо — сайт публічний)
На відміну від старого інструменту в Google Таблиці, цей сайт буде на публічній адресі (GitHub Pages), тож ключ варто обмежити одразу:
1. Натисни на щойно створений ключ у списку.
2. **Application restrictions → Websites (HTTP referrers)**.
3. Додай адресу сайту, наприклад: `https://<ваш-акаунт>.github.io/ses-calculator/*`
   (Точну адресу я підкажу після публікації на кроці 8 — поки можна лишити не обмеженим і повернутись сюди пізніше.)
4. **API restrictions → Restrict key** → познач два API з кроку 3 → **Save**.

## 6. Вставити ключ у сайт
1. Відкрий файл `panels.js` у папці сайту.
2. На початку файлу знайди рядок `const MAPS_API_KEY = "";`
3. Встав ключ між лапками: `const MAPS_API_KEY = "AIza...";`
4. Збережи файл.

---

**Коли ключ буде на руках і вставлений у файл — скажи «готово», перевіримо разом.**
