# Шаг 2. Установка инструмента «Розкладка панелей»

## 1. Вставить код
1. Открой свою таблицу → **Расширения → Apps Script**.
2. Слева нажми **«+» → Script**, назови файл, например `Панелі`.
3. Вставь весь код из файла **`Панелі_AppsScript.gs`**.

## 2. Вставить ключ (один раз, отдельно от кода)
Ключ хранится в настройках проекта, поэтому при обновлениях кода он больше не теряется.

1. В Apps Script слева нажми **⚙ Project Settings** (шестерёнка).
2. Прокрути до **Script Properties** → **Add script property**.
3. Property = `MAPS_KEY`, Value = твой ключ Maps API (`AIza...`) → **Save script properties**.

Всё. Больше ключ в код вставлять не нужно — при любых обновлениях кода он остаётся.

## 3. Добавить пункт в меню
Открой файл с КП-скриптом, найди функцию `onOpen` и добавь в меню одну строку (`.addItem` с розкладкою):

```
function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu('📄 КП')
    .addItem('Сформувати КП (PDF)', 'generateProposalPDF')
    .addItem('🗺️ Розкладка панелей', 'openPanelTool')
    .addToUi();
}
```

**Save**, затем обнови вкладку с таблицей.

## 4. Как пользоваться (менеджер)
Меню **«📄 КП» → «🗺️ Розкладка панелей»** → откроется окно с картой:
1. Введи адрес клиента (или координаты вида `50.45, 30.52`) → **Знайти**.
2. **✏️ Обвести дах** — кликай по углам крыши/ската, замкни двойным кликом. Контур можно подправлять, перетаскивая точки.
3. Ползунком **«Кут рядів»** разверни панели вдоль ската. При желании переключи вертикально/горизонтально.
4. **▦ Розкласти** — панели разложатся, справа покажет «N панелей · X кВт».
5. **💾 Зберегти в КП** — картинка сохранится на Google Диск (тека `КП/Розкладки`), появится ссылка.

## Важно про ключ
Если ты ограничивала ключ — оставь пока только **ограничение по API** (Maps JavaScript, Maps Static, Geocoding), **без** ограничения по сайту (referrer). Окно Apps Script работает на домене `googleusercontent.com`, и referrer-ограничение его заблокирует. Сайтовое ограничение добавим позже, если понадобится.

## Параметры панели
Заданы под твою панель (2382×1134 мм, 620 Вт). Если поменяешь модель — правь блок `PANEL` вверху файла (`L_MM`, `W_MM`, `WATT`, зазор `GAP_M`, отступ от края `SETBACK_M`).
