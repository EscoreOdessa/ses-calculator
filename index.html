Колонка «Матеріали+робота» — загальна сума (не за кВт!) для «Ручний ввід обладнання»: інвертор (нижче) + ця сума замінюють орієнтовну $/кВт, коли менеджер вручну задає потужність інвертора.

Ціна конкретного інвертора + рядок «Матеріали+робота» вище використовуються замість орієнтовної $/кВт, коли менеджер вручну задає потужність інвертора. Потужність (кВт) має збігатись зі списком інверторів вище.

Розкладка панелей на даху

Знайдіть адресу → «Обвести дах» (клікайте по кутах даху на карті, потім «Готово») → панелі розкладуться самі. Кількість підтягується з калькулятора (можна змінити вручну); ряди заповнюються з південного краю — там сонця найбільше. Кутом рядів вирівняйте їх вздовж схилу даху.

Не задано ключ Google Maps API (потрібен для пошуку адреси). Впишіть його у panels.js — див. «Налаштування_Google_Cloud.md». Якщо адреса вже введена як координати, можна порахувати і без ключа.

Виробництво електроенергії (PVGIS)

Орієнтовне річне та помісячне виробництво станції за даними безкоштовного сервісу PVGIS (Європейська комісія). Кут кріплень береться той самий, що і в «Розкладці панелей» (15/20/30°, підігнаний під ідеальний).

Комерційна пропозиція

Формується автоматично з даних калькулятора. Натисніть «Друкувати / Зберегти PDF» — відкриється системне вікно друку браузера, де можна обрати «Зберегти як PDF».
