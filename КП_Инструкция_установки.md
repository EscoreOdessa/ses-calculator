# Кнопка «Сформировать КП (PDF)» — установка

Скрипт берёт данные с листа «Калькулятор», верстает коммерческое предложение и сохраняет его в PDF на твой Google Диск (в папку «КП»). После генерации показывает ссылку на файл.

## Шаг 1. Вставить код
1. Открой свою Google-таблицу с калькулятором.
2. Меню **Расширения → Apps Script**.
3. Удали то, что есть в файле `Код.gs`, и вставь весь код из файла **`КП_AppsScript.gs`**.
4. Нажми **Сохранить** (значок дискеты).

## Шаг 2. Запустить один раз (выдать разрешения)
1. В Apps Script вверху выбери функцию **`generateProposalPDF`** и нажми **Выполнить**.
2. Google попросит разрешения — **Разрешить** (нужно для создания PDF и сохранения на Диск).
3. Скрипт один раз отработает на текущих данных — проверь, что PDF появился.

## Шаг 3. Сделать кнопку на листе «Калькулятор»
Есть два способа — выбери любой.

**А) Пункт меню (проще всего, ничего рисовать не надо)**
После сохранения кода обнови вкладку с таблицей. Сверху появится меню **«📄 КП» → «Сформировать КП (PDF)»**. Готово.

**Б) Кнопка прямо на листе**
1. На листе «Калькулятор»: **Вставка → Рисунок**.
2. Нарисуй прямоугольник, впиши текст «Сформировать КП», **Сохранить и закрыть**.
3. Кликни по рисунку → три точки в углу → **Назначить скрипт**.
4. Впиши имя функции: `generateProposalPDF` → ОК.
5. Теперь нажатие на кнопку формирует КП.

## Что попадает в КП
- Тип станции, расположение, форма оплаты, мощность станции, инвертор DEYE.
- Для гибридной — блок АКБ (часы автономии, требуемая ёмкость, модель/модуль, количество — то, что есть на листе).
- Цена за кВт и ИТОГО в $ и в гривне по курсу.

## Если что-то не подтянулось
Скрипт ищет данные **по названиям строк** (меткам), а не по адресам ячеек. Если какая-то подпись на листе называется иначе — открой код, найди блок `LABELS` вверху и добавь свой вариант названия в нужный массив. Например, если у тебя строка называется «Потужність, кВт», допиши её в `power: [...]`.

Настройки шапки КП (название компании, контакты, имя папки) — там же вверху, блок `CFG`.
