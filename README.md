# Калькулятор СЕС (ESCORE)

Розрахунок орієнтовної потужності та ціни сонячної електростанції для першого дзвінка з клієнтом.

## Робочий інструмент

Калькулятор — Google Таблиця, весь розрахунок і кнопки (КП, Розкладка панелей, Виробництво) працюють тільки там:

https://docs.google.com/spreadsheets/d/1fVpkQ1hISLlMFAyUjumawSkas6a85gnFciHO2rpJr7U/edit
https://docs.google.com/spreadsheets/d/1fVpkQ1hISLlMFAyUjumawSkas6a85gnFciHO2rpJr7U/edit?usp=sharing


## Що в цьому репозиторії

Знімок вихідного коду Apps Script та інструкцій — для версіонування і резервної копії, не для запуску:

- КП_AppsScript.gs — формування КП (PDF)
- Панелі_AppsScript.gs — розкладка панелей на даху
- Виробництво_AppsScript.gs — оцінка виробітку електроенергії (PVGIS)
- Рядок20_Панелі_AppsScript.gs — допоміжний фрагмент
- Калькулятор_СЭС.xlsx — резервна xlsx-версія калькулятора
- інші файли — інструкції з установки
